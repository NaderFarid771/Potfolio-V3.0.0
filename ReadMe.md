# Front-End Developer Portfolio — Nader Farid

A clean, fast, and responsive personal portfolio website built from scratch using pure HTML5 and CSS3. Designed to showcase front-end code execution, layout structuring, and design-to-code projects.

## Overview

This repository contains the source code for my personal front-end portfolio. The layout focuses on clarity, fast loading times, and responsive adaptation across devices without relying on external CSS frameworks.

## Key Features

- **Semantic HTML5 Markup:** Structured with proper layout landmarks (`header`, `nav`, `main`, `section`, `footer`).
- **Flexbox & CSS Grid Layouts:** Used Flexbox for header navigation, hero alignment, and workflow steps, combined with CSS Grid for capability boxes and project cards.
- **Responsive Design:** Adapts cleanly to desktop, tablet, and mobile screens using media queries.
- **Warm Dark Palette:** Custom charcoal and terracotta color scheme for comfortable reading and high contrast.

## Tech Stack

- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries)
- Google Fonts (`Plus Jakarta Sans`)

## Project Structure

- `index.html` — Main page structure and content
- `style.css` — Layout styling and responsive breakpoints
- `README.md` — Project documentation

## Run Locally

Open `index.html` directly in any modern web browser.
